# 项目说明

这是一个基于 C++ 面向对象思想实现的即时通信系统课程设计项目，采用 JZY 命名规范。

## 目录结构

- `include/`：头文件
- `src/`：源文件
- `CMakeLists.txt`：CMake 构建配置

## 编译运行

```bash
mkdir -p build
cd build
cmake ..
make
./CHATJZY
```

## 当前实现状态

- 用户类
- 平台抽象类
- QQ 平台类
- 微信平台类
- 微博平台类
- 好友类
- 群类
- 文件管理类
- 系统菜单界面

这是一个可扩展的课程设计框架，后续可继续补充好友管理、群管理、登录注册、绑定功能等。
